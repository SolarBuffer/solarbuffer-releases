# SolarBuffer releases

De openbare releasegeschiedenis van de SolarBuffer Hub-software.

De software zelf staat in een gesloten repository. Hier staan alleen de
release-notities, zodat de links vanuit de Hub naar een vindbare pagina wijzen.
Elke versie staat onder [Releases](../../releases).

Zoek je de SolarBuffer-integraties, die zijn wel open:

- [Home Assistant](https://github.com/SolarBuffer/solarbuffer-homeassistant)
- [Homey](https://github.com/SolarBuffer/solarbuffer-homey)

Vragen over je eigen installatie? Mail info@solarbuffer.nl.
